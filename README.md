# 🌌 Celestial Bodies Database

A **PostgreSQL relational database project** completed as part of the **freeCodeCamp Relational Database Certification**.

## 📚 About

This project contains a database of celestial bodies and their relationships, including:

* 🌌 **Galaxies**
* ⭐ **Stars**
* 🪐 **Planets**
* 🌙 **Moons**
* ✨ **Constellations**

The database uses **primary keys, foreign keys, unique constraints, and relational data** to connect the different celestial bodies.

## 🛠️ Technologies

* PostgreSQL
* SQL
